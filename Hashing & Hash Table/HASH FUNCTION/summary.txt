-----------Hash Functions-----------------
Function yang mengubah key menjadi index

1. Mid Square
    Ambil digit tengah dari hasil kuadrat key

    e.g:
    key = 123
    (123)^2 = 15129

    Ambil tengah -> 512

2. Division
    Metode modulo (%)

    e.g:
    key = 23
    TABLE_SIZE = 10
    --> 23 % 10 = 3

3. Folding
    Key dipecah, lalu dijumlahkan

    e.g:
    key = 123456
    --> 123 + 456 = 579
    --> 579 % TABLE_SIZE 

4. Digit Extraction
    Ambil digit tertentu saja dari key

    e.g:
    Key = NIM : 260245123

    Ambil 3 digit terakhir --> 123

5. Rotating Hash
    Biasanya untuk String
    --> menggeser bit(rotate left / right) dari hash sebelumnya
    --> lalu, ditambah / di-XOR dengan char sebelumnya 

    e.g:
    "ABC" --> "CBA"
